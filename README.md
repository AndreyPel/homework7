# Домашнее задание к работе 7

## Условие задачи

Написать программу, которая выводит название введенного знака препинания

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **НАЧАЛО**
2. Объявление переменной ch
3. Вывод "Введите знак препинания: "
4. Ввод символа с клавиатуры и сохранение его в переменную ch.
5. Выбор ветвления с помощью оператора switch(ch):
  - . вывод «Точка»;
  - , вывод «Запятая»;
  - ; вывод «Точка с запятой»;
  - : вывод «Двоеточие»;
  - ! вывод «Восклицательный знак»;
  - ? вывод «Вопросительный знак»;
5. **КОНЕЦ**
